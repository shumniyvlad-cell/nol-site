# «НОЛЬ» — визуальный blueprint v2

Статус: визуальное проектирование завершено, код не начат.

## 1. Арт-директорское решение

V1 сохраняется как функциональный baseline, но отклоняется как финальная визуальная система: слишком много повторяющихся split-layout, карточек, колонок и привычных CTA.

V2 строится как последовательность самостоятельных плакатов. Их объединяет не шаблон секции, а один сюжет:

`горизонт → документ → сгиб → калибровка → порог → маргиналия → проекция → титры → рассвет`

Рабочее название системы: **«Архив возвращённого будущего»**.

## 2. Неподвижные правила системы

1. Один экран — одна метафора, один композиционный жест, одна пользовательская функция.
2. Кольцо каждый раз меняет роль: горизонт, разрез, прокол, порог, регистрационная метка, проём.
3. Красный — только активный сигнал. Не более одного доминирующего красного элемента в viewport.
4. Пустота является содержанием. Она не заполняется карточками, бейджами и декоративными сетками.
5. Все смысловые тексты, контролы и статусы существуют в HTML. Растровые концепты задают свет и композицию.
6. Плакатность не отменяет доступность: фокус, клавиатура, семантика, контраст и размер цели остаются обязательными.

| Диапазон | Материал | Смысл |
|---|---|---|
| Hero | Чёрная вода и холодный горизонт | Состояние до решения |
| Проблема | Жилая комната и свет проектора | Частная ситуация становится видимой |
| Поворот | Чёрный лист, раскрывающий белую плоскость | Смена определения банкротства |
| Диагностика | Матовая калибровочная бумага | Факты вместо давления |

| Медиа | Плёнка, кресло, проектор | Человек важнее контентной упаковки |
| Философия / team | Корректорская полоса и титры | Ответственность вместо social proof |

## 4. Типографика

- Основной шрифт: Manrope.
- Системный индекс: IBM Plex Mono.
- Display desktop: `64–112px`, вес `550–600`, line-height `.94–1.02`.
- Display mobile: `46–58px`, вес `550–600`.
- Основной текст: `18–22px` desktop, `17–19px` mobile.
- Ни один заголовок не тяжелее `600`, включая манифест.
- Крупный номер может выходить за viewport, но вопрос, ответ и действия не обрезаются.
- У короткого заголовка допустим один осмысленный перенос; связные абзацы не разбиваются на псевдодраматические строки.

## 5. Экранная режиссура

### 01. Hero — «Горизонт»

- Горизонт проходит через весь viewport и связывает текст с порталом.
- H1 является главным пространственным объектом; портал не занимает отдельную «правую колонку».
- Primary и secondary action выглядят как маршруты с подчёркиванием, без красной заливки.
- Движение: один вступительный проход горизонта и проявление материала кольца, суммарно не более `1.4s`.

### 02. Проблема — «Комната-документ»

- Фото занимает весь экран.
- Заголовок проецируется на свободную стену, наблюдения работают как архивная строка внизу.
- Единственный красный сигнал — экран телефона.
- Движение: однократное включение проектора при входе секции; без бесконечного мерцания.

### 03. Поворот бренда — «Сгиб»

- Чёрная плоскость раскрывает белую как физический лист.
- Портал появляется не поверх фона, а в апертуре сгиба.
- Четыре состояния знака образуют один материальный след, а не ряд карточек.
- Движение: один scroll-linked reveal с ограниченным диапазоном; reduced motion показывает финальное раскрытое состояние.

### 04. Диагностика — «Калибровочный лист»

- Номер шага занимает поле экрана и пересекается с вопросом.
- Ответы — типографические строки; выбранный ответ оставляет красный прокол.
- Семь точек по краю — реальный progress, не декор.
- Движение: только смена активной точки и вдавливание выбранного radio.

### 05. Процесс — «Один порог»

- Одновременно доминирует один этап.
- Остальные этапы остаются координатами и маленькими световыми проёмами.
- При смене этапа меняется состояние света, а не вся композиция.
- Движение: один переход света между пятью состояниями; без горизонтального scroll hijacking.

### 06. Legal / цена — «Маргиналии»

- Вопросы формируют библиотечный индекс.
- Открытый ответ находится в чёрной маргиналии и визуально пересекает активный вопрос.
- Цена «от 300 000 ₽» — колофон, не тарифная карточка.
- Движение: индекс смещает одну регистрационную точку; ответ меняется коротким crossfade.

### 07. Медиа — «Пустое кресло»

- Кресло — главный герой.
- «ПОСЛЕДНИЙ ПЛАТЁЖ» работает как световая заслонка за ним.
- Три материала остаются реальными ссылками, но располагаются контактной лентой.
- Play открывает доступный teaser dialog; подписка встроена в ту же проекционную сцену.
- Движение: включение проектора при входе; hover/focus двигает плёнку на один кадр, без autoplay.

### 08. Философия / launch mode / team — «Титры»

- «Мы не продаём чудо» — единственный крупный тезис.
- Четыре принципа идут одной последовательностью.
- Launch mode выглядит как честный статус публикации.
- Роли команды показаны титрами с незаполненными именами; портретов и силуэтов нет.
- Движение: отсутствует. Здесь идея должна держаться без эффекта.

### 09. Финал — «Уже по другую сторону»

- Каменный проём сам образует разомкнутое кольцо.
- Человек уже прошёл порог; сцена не обещает мгновенного спасения.
- CTA нанесены на линию маршрута; footer — одна архивная строка.
- Движение: минимальный parallax глубины до `16px` и однократное повышение luminance; reduced motion полностью статичен.

### 10. Mobile — «Вертикальный монтаж»

- Крупные объекты обрезаются смелее, чем на desktop.
- Hero: портал выходит за верхний правый край, горизонт разрезает экран.
- Диагностика: номер становится фоном и выходит за два края.
- Все действия сохраняют цель не меньше `48×48px`.
- Один экран не превращается в длинную колонку одинаковых блоков; ритм меняется секция за секцией.

## 6. Motion-бюджет

Количество эффектов не увеличивается. На секцию разрешён максимум один смысловой переход.

| Экран | Разрешено | Запрещено |
|---|---|---|
| Hero | Горизонт + сборка материала как единый intro | Постоянная реакция частиц на курсор |
| Проблема | Включение проекции | Flicker, glitch, шум поверх текста |
| Поворот | Раскрытие сгиба | Дополнительный parallax объектов |
| Диагностика | Radio puncture | Анимированные иллюстрации и конфетти |
| Процесс | Смена света | Пять независимых анимаций этапов |
| Legal | Смена маргиналии | Accordion bounce |
| Медиа | Проектор / один кадр плёнки | Autoplay и бесконечный carousel |
| Манифест | Ничего | Reveal каждой строки |
| Финал | Незаметная глубина | Glow-кольцо и победный zoom |

## 7. Контентные и юридические границы

- Не создавать отзывы, цифры, судебные дела, имена и фотографии.
- Launch mode включён по умолчанию.
- Юридические ответы редактируются отдельно от компонентов.
- Возле изменяемой информации сохраняется оговорка об обстоятельствах дела и актуальной редакции законодательства.
- Цена: только «от 300 000 ₽»; итог фиксируется после анализа ситуации.
- Не обещать списание любых долгов или гарантированный результат.
- До получения реальных данных команда показывается ролями и статусом подготовки.
