# Image Gen — журнал визуальных концептов

Режим: встроенный Image Gen. CLI/API fallback не использовался.

Все изображения являются дизайн-концептами. Они не содержат утверждённый юридический или продуктовый контент и не должны публиковаться как интерфейс.

## 01 — Hero desktop

- Выход: `concepts/01-hero-desktop.png`
- Референс: `01_nol_netflix_slide.png`.
- Финальный brief: desktop 1440×900; прозрачный header; точный hero-контент из ТЗ; текст слева в 6–7 колонках; крупный off-center портал справа; частицы, мокрый отражающий пол, горизонтальная дымка; почти чёрная палитра; одна красная точка; весь UI code-native; без инвесторского текста, streaming-интерфейса, юридических клише, badges и карточек.
- Коррекция: красную CTA из результата не принимать; использовать светлую CTA.

## 02 — Problem desktop

- Выход: `concepts/02-problem-desktop.png`

## 10 — Mobile hero and diagnostic

- Выход: `concepts/10-mobile-hero-diagnostic.png`
- Референсы: созданные концепты `01` и `04`.
- Финальный brief: два самостоятельных mobile-screen 390×844; hero не сжимает desktop layout, portal выше/позади текста и не мешает чтению; 20px gutters, header ≤64px, CTA ≥52px; diagnostic 02/07 с full-width rows и thumb-friendly controls; WebGL не требуется; без horizontal overflow и card stack.
- Коррекция: при реализации высота portal-области hero ограничивается 32–36vh.
